스프레드 정의 · 보간 · 계산 기준

기간스프레드 같은 국가 곡선에서 (A 금리 − B 금리) × 100으로 계산합니다. 금리 원값은 %, 결과는 bp입니다. 기본 순서는 장기−단기이며, 순서를 바꾸면 부호가 반대입니다. 음수이면 해당 A가 B보다 낮다는 뜻입니다.

한국 크레딧스프레드 신용채 수익률 − 동일 만기 한국 참조금리의 차이입니다. 동일 만기는 원본 만기명(‘N년 이하’ 구간) 기준이며 잔존만기·듀레이션이 같다는 뜻은 아닙니다. 원본 한국 3M·6M·9M은 BONDAVG14, 1Y 이상은 BONDAVG01 계열입니다. 단기 참조금리의 채권 종류는 확인되지 않아 국채 대비로 단정하지 않습니다. ‘한국_기준금리’ 정책금리는 차감하지 않습니다.

OAS 원본 미국 IG·HY OAS를 그대로 사용하며 이미 조정된 스프레드에서 국채금리를 다시 차감하지 않습니다. 원본 숫자 규모에 따라 bp로 해석한 기존 대시보드 전제를 유지합니다. 원본에 단위가 명시되어 있지 않아 외부 OAS 시계열과 직접 대조한 검증은 아닙니다.

보간 기본은 관측 만기 일치입니다. 보간 허용을 선택하면 두 인접 만기 금리를 만기 거리에 비례해 가중 평균합니다. 예: 2.5년 = 2년과 3년의 50:50 평균. 실측 2.5년 값이 아니며 외삽하지 않습니다. 직접 선택에서 만기가 다르면 금리곡선 효과가 함께 포함됩니다.

동일 날짜 두 구성값이 모두 있는 날짜만 계산하며 결측을 이월하거나 0으로 대체하지 않습니다. 보간은 같은 날짜에 두 기준금리가 모두 있어야 합니다. 변동은 조회일 스프레드 − 상단에서 선택한 비교일 스프레드입니다.

0값 기본은 원본 0값 보존입니다. ‘구성 원값 0 제외’는 선택한 구성금리·OAS가 0인 날짜를 이 분석에서만 제외합니다. 두 유효금리가 같아 생기는 0bp 스프레드는 유지합니다. 실제 0금리도 제외될 수 있으므로 자료 특성에 맞게 선택하세요.

이동 통계 Z-score는 스프레드 수준의 이동 평균·표본 표준편차로 계산하고 현재 관측을 포함합니다. 변동성은 인접 원본행 간 bp 차분의 이동 표본 표준편차이며 비연율입니다. 결측 없는 전체 창만 사용하고 분석 시작일 이전 이력도 준비 구간으로 사용합니다. ±2는 참고선이며 매매신호가 아닙니다.

해석 범위 만기 일치 수익률 차이에도 신용·유동성·세금·옵션 등 여러 요인이 포함될 수 있습니다. OAS와 단순 수익률 차이는 정의가 달라 동일 척도로 직접 비교하지 않습니다. 본 기능은 인과관계 추정이나 예측 모형이 아닙니다.

정의 참고: FRED 10년−2년 금리차. 계산에는 업로드한 엑셀 저장값만 사용합니다.

변환 자동 모드에서 금리 %는 직전 행 대비 bp 차분, FX는 단순 수익률 %, 나머지는 원단위 차분입니다. OAS는 이미 bp이므로 원단위 차분을 사용합니다. 수준값은 원값을 분석합니다. 구성한 스프레드의 자동 변동은 bp 차분이며 ×100을 다시 적용하지 않습니다.

날짜·결측 변환은 원본의 인접한 날짜행에서 먼저 계산합니다. 결측을 건너뛰지 않으며, 수익률은 현재·직전 값 모두 양수일 때만 계산합니다. 회귀는 분석 기간 내 같은 날짜의 유효 X·Y 쌍만 사용합니다.

회귀 β = Sxy/Sxx, α = 평균(Y) − β·평균(X), R² = 1 − SSE/Syy. 최소 3개 관측쌍이 필요합니다. 상수 X는 계산 불가, 상수 Y는 상관계수·R²가 정의되지 않습니다. 잔차 표준편차 = √(SSE/(n−2)).

이동 계산 선택한 창은 원본 관측행 수입니다. 창의 모든 필요한 값이 존재할 때 계산합니다. 표준편차는 n−1을 분모로 사용하며 Z-score 창에 현재 관측을 포함합니다. 상수 창의 Z-score는 비웁니다. 수치 오차 범위의 미세변동은 상수로 취급합니다 (절대 10⁻¹² 또는 값 크기 × 8 × 기계 정밀도 이하). 차트 시작 이전 데이터도 준비 구간으로 사용합니다.

연율화 기본값은 비연율 표준편차입니다. √252 옵션은 연 252관측일과 변동의 독립성을 가정한 배율이며, 원본의 휴장·날짜 간격을 조정하지 않습니다. 수준값에는 연율화를 적용하지 않습니다.

해석 β 단위는 Y 단위 / X 단위입니다. 상관·회귀는 인과관계나 미래 예측을 뜻하지 않습니다. 수준값의 공통 추세와 원본 0값이 결과에 영향을 줄 수 있습니다. ±2는 Z-score 참고선이며 통계적 유의성이나 매매신호를 뜻하지 않습니다.

스냅샷 공개 페이지에는 원본 관측값이 없습니다. Excel 업로드 후 데이터는 메모리에서 분석하며, 새로고침하면 다시 업로드해야 합니다. 데이터 포함 HTML 저장으로 받은 파일만 해당 관측값을 포함하고 독립 실행할 수 있습니다. 원본 Excel 변경은 자동 반영되지 않습니다.

범위 제한 원자재 시계열이 없어 원자재 섹션을 구성하지 않았습니다. 시장별 종가 시점·시간대와 휴장일은 원본의 공통 날짜행을 따릅니다.

원본 공급 단계 원본 Excel에는 infomax RTD 저장값과 ‘토/일/휴장일 삭제, 비거래일 이전값’ 설정 메모가 있습니다. 앱은 결측을 채우지 않지만 원본 저장값 자체가 이전 관측값으로 대체되어 있을 가능성이 있습니다. 공급 단계 처리는 이 앱에서 재검증하거나 복원하지 않습니다.

비교 방법 직전 / 5 / 21관측일은 원본 날짜행의 간격입니다. 달력일·시장별 영업일과 다를 수 있습니다. 해당 날짜의 저장값을 그대로 비교하며 결측값을 전일 값이나 0으로 채우지 않습니다.

단위 금리·신용채 수익률은 %로 해석하고 차이는 ×100하여 bp로 표시합니다. 미국 IG/HY OAS는 원본 숫자 규모를 바탕으로 bp로 해석합니다. FX 변동은 (현재 ÷ 비교 − 1) ×100, 기타 지표는 원단위 절대 차이입니다.

이름과 단위 주의 USDEUR·KRWJPY는 원본 명칭과 수치를 유지했습니다. 헤지 프리미엄·일부 선물 및 추가 인식 지표는 명시 단위가 없어 ‘원자료’로 표시합니다. 추가 인식 지표는 전체 탐색·수준 차트·기초통계·회귀에서 사용할 수 있습니다. 단위 미확인 지표는 크레딧스프레드의 금리 후보에서 제외합니다. 기준곡선 후보 역시 단위를 확인한 기존 정의를 사용하므로 업로드 파일에 같은 만기 이름이 있어도 단위가 미확인인 추가 열은 보간 기준으로 사용하지 않습니다. 중복 지표명은 원본 열과 9행의 필드로 구별했습니다.

0 및 결측 원본의 0은 유효 여부를 단정하지 않고 그대로 보존합니다. 조회값이 0이면 ‘0값 확인’을 표시합니다. ‘—’는 결측 또는 계산 불가입니다. 음수·0의 기준값으로 지수화하지 않습니다.

차트 범위 1M·3M·1Y·3Y는 조회일에서 달력 기간을 차감하며 월말은 해당 월의 마지막 날로 보정합니다. 직접 설정은 입력한 시작일과 종료일 안의 관측만 사용합니다. 추이 차트와 전체 표의 최저·최고가 같은 기간을 사용합니다.

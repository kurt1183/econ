## 배포와 공개 페이지 접속

배포된 [https://kurt1183.github.io/econ/](https://kurt1183.github.io/econ/)을 브라우저로 직접 열고 새로고침했습니다. 공개 초기 화면에는 관측 데이터가 없고 엑셀 업로드는 활성화, 데이터 포함 HTML 저장은 비활성화된 상태를 확인했습니다. [공개 초기 화면 캡처](public-page.jpg)에는 업로드한 금융 관측값이 없습니다.

## 합성자료 Chromium 회귀검증

GitHub Actions에서 단위 테스트 25개와 Chromium 통합 테스트 9개가 통과했습니다. 이전 [PR 검증 실행](https://github.com/kurt1183/econ/actions/runs/38665220259)의 코드 커밋은 `47bc13e99c986676b8cad60c23db3cc5880e2b46`이며, 배포 실행에서도 테스트를 통과했습니다.

브라우저 CI는 302개 합성 계열·96일의 XLSX를 사용했습니다. 업로드·오류 처리·기간·검색·CSV·스프레드·계량분석·확대·범례·저장 HTML 오프라인 재개방·새로고침을 검사했습니다. 해당 경로에서 JavaScript 런타임 오류가 없었고 페이지 로드 이후 비탐색 HTTP 요청이 없었습니다. 1440px 성공 화면 캡처도 직접 확인했습니다. 실제 Excel은 CI 입력·공개 artifact·공개 로그에 넣지 않았습니다.

## 검증 한계와 남은 항목

- **실제 데이터 포함 HTML의 재개방은 미검증입니다.** 파일 다운로드는 성공했지만 검증용 클라우드 브라우저의 URL 정책이 `file://` 접근을 차단했습니다. 동일 기능의 합성자료 오프라인 재개방은 Chromium CI에서 통과했습니다. 실제 다운로드 파일을 로컬 브라우저로 열어 관측 수·표본기간·차트·새로고침을 확인하면 이 항목을 재검증할 수 있습니다.
- 실제 파일의 업로드와 확인한 화면·CSV 경로는 통과했으나 모든 변수 조합·모든 기간·장시간 사용의 성능을 전수 검사한 것은 아닙니다. Safari·Firefox 등 다른 브라우저 검증은 수행하지 않았습니다.
- 위의 1,860,320셀 전수 일치는 파서 출력과 독립 추출의 비교입니다. 실제 배포 화면의 모든 셀을 하나씩 검사했다는 뜻이 아닙니다. 실제 브라우저 CSV의 별도 대조 범위는 5,704셀입니다.
- 동일 원본을 서로 다른 파서로 읽거나 서로 다른 계산 도구로 대조한 결과는 원천 금융자료 자체의 시장 정확성을 독립적으로 검증하지 않습니다. 단위·FX 방향·배율의 원자료 확인과 재배포 라이선스 확인도 미완료입니다.
- 콘솔 무오류는 관측한 실행 경로의 결과입니다. CI의 외부 통신 검사는 로드 이후 비탐색 HTTP 요청을 대상으로 하며 모든 통신 방식에 대한 포괄적 보안 감사가 아닙니다.

## 검토에서 수정한 오류

- 업로드 범주명이 HTML로 해석되던 경로를 이스케이프하고 안전한 범주 사전을 사용했습니다.
- 빈 상태에서 실패한 업로드 후 HTML 저장 버튼이 켜지던 오류를 수정했습니다.
- 저장 HTML 재개방 시 신규 EQUITY 범주가 선택 목록에서 누락되던 오류를 수정했습니다.
- 수치 오차 범위의 상수 계열이 산점도에서 큰 분산으로 확대되지 않도록 표준편차 판정과 축 여백을 일치시켰습니다.
- 저장 HTML의 추가 지표가 다음 업로드의 필수 지표로 굳어지지 않도록 기준 260개 정의만 필수로 유지했습니다.

빈 상태 오류·신규 범주·저장 재개방은 Chromium 회귀검증에 포함됐습니다. 최종 변경 이후 수치 모듈은 실제 데이터 대조 당시 해시와 동일합니다.

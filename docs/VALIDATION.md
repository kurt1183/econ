# 검증 기록

## 입력과 공개 범위

2026-10-15에 `AI_Credit/FICC_Monitor.html`과 `data_info.xlsx`의 완전본을 확인했습니다. Excel 파일 크기는 11,485,524바이트이며 ZIP 구조 검사를 통과했습니다. 원본 파일과 실제 데이터로 만든 중간 결과는 공개 저장소 밖에서만 사용했습니다.

공개 HTML은 날짜·값·원본 행 배열이 비어 있으며 기존 260개 지표의 매핑 정의만 포함합니다. 브라우저 업로드 시 신규42개까지 총302개를 인식합니다. 원본 Excel의 작성자·개인 경로·숨김 시트·비공개 Drive URL은 공개 코드에 없습니다.

## 브라우저·배포 검증 상태

현재 작업 환경에는 허용된 브라우저 제어 기능이 제공되지 않아 로컬 실제 브라우저 검사를 수행하지 않았습니다. PR의 GitHub Actions에서 합성 Excel을 이용한 Chromium 통합 테스트를 실행하도록 준비했습니다. 실행 결과를 확인하기 전 성공으로 간주하지 않습니다.

| 필수 항목 | 현재 근거와 제한 |
| --- | --- |
| 공개 홈페이지 접속 | 병합 승인·Pages 설정·배포 전이므로 미검증 |
| JavaScript 런타임 오류 | 구문 검사 통과. 브라우저 실행 결과 대기 |
| Excel 업로드 | 파서가 실제 XLSX를 정확히 읽음. 브라우저 파일 선택 통합은 CI 대기 |
| 실제 Excel 값 | 1,860,320셀 전수 일치 |
| 날짜 변경 차트/계산 | 기간 모듈 검사 통과. 브라우저 상호작용은 CI 대기 |
| 기간·크레딧 계산 | 실제 데이터와 기준 계산 일치, 단위 전제 별도 |
| 계량 결과 | 위 표의 수치 범위에서 기준 계산 일치 |
| 새로고침 | 브라우저 CI 및 배포 후 검증 대기 |

GitHub CI에는 실제 Excel을 넣지 않습니다. CI 합성자료로 업로드가 통과해도 실제 11MB Excel의 브라우저 메모리·처리시간·전체 시각 검증을 대신하지 않습니다. 독립 파서 두 경로가 같은 파일을 읽은 일치는 원천 금융자료가 정확하다는 독립 검증도 아닙니다.

## 재현

```bash
python3 scripts/build.py
node tests/public-artifact.cjs
npm test
```

NumPy/SciPy/openpyxl이 있는 개인 환경에서는 다음과 같이 실제 원본을 비공개 경로에서 대조할 수 있습니다. 출력 경로를 저장소 안으로 지정하면 거부합니다.

```bash
python3 scripts/reference_check.py --workbook /private/data_info.xlsx --output /private/ficc-validation
```

실제 원본 및 계산 결과를 PR·Actions artifact·공개 로그에 첨부하지 마십시오.

# FICC Monitor

Google Drive `AI_Credit`의 `FICC_Monitor.html` 기능을 보존·개선한 한국어 FICC 정적 대시보드입니다. 공개 페이지에는 관측 데이터를 넣지 않습니다. 사용자가 `data_info.xlsx`를 선택하면 해당 브라우저 메모리에서 분석합니다.

## 배포 상태

- 저장소: https://github.com/kurt1183/econ
- 작업 브랜치: `feat/ficc-monitor-20261015`
- Pull Request: https://github.com/kurt1183/econ/pull/1
- 검증: 실제 Excel 전수 대조, 단위 테스트 25개, Chromium 통합 테스트 9개 통과
- 예정 GitHub Pages 주소: https://kurt1183.github.io/econ/
- 현재 기본 브랜치 병합·Pages 활성화·외부 접속 검증은 대기 중입니다. 위 주소는 배포 완료로 확인된 주소가 아닙니다.

기본 브랜치 병합은 소유자 승인 후 수행합니다. 원본 Excel과 내장 시계열 데이터의 공개 승인은 요청하지 않으며, 이번 변경에는 포함하지 않습니다.

## 사용법

1. 배포된 페이지 또는 내려받은 `index.html`을 Chrome·Edge 등 최신 브라우저에서 엽니다.
2. **엑셀 업로드**에서 `data_info.xlsx` 또는 같은 `DailyRate` 구조의 `.xlsx`를 선택합니다.
3. 조회 기준일·비교 간격·시작일·종료일을 선택합니다. **전체 분석에 적용**은 차트·기간통계·회귀·스프레드·CSV 표본기간에 반영됩니다.
4. 지표명·티커·열로 검색하고 수익률곡선, 기간·크레딧스프레드, 계량분석을 확인합니다.
5. CSV로 결과를 내려받습니다. **현재 데이터로 HTML 저장**은 관측값을 포함한 개인용 독립 실행 파일을 만듭니다. 이 파일을 공개하면 데이터도 공개됩니다.

공개 페이지 새로고침 시 업로드 데이터는 지워집니다. 개인용 저장 HTML은 저장한 데이터를 다시 엽니다. 파일 업로드는 서버·GitHub·Drive로 전송되지 않으며 별도 유료 서버·API 키·CDN이 필요하지 않습니다. 인쇄 기능과 기존 HTML 저장 기능을 유지합니다.

## 기능

- 한국·미국·일본·독일·호주·영국 금리와 수익률곡선, 외환·헤지·수급·선물 모니터링
- 같은 국가의 두 만기 선택·순서 교환에 따른 기간스프레드
- 한국 신용채와 참조금리의 동만기 차이, 명시적으로 선택하는 선형 보간·기준 만기 직접 선택, 미국 OAS
- 지표 검색·분류·정렬, 원본 위치·변수명·단위·결측·0값 확인
- 기초통계·Pearson 상관·절편 포함 OLS·이동평균·표준편차·Z-score·X/Y 시계열 비교
- 달력 기준 빠른 기간과 자유로운 시작/종료일, 차트 확대·축소·이동·범례 토글
- 조회 결과·스프레드·계량분석 CSV, 인쇄, 데이터 포함 HTML 저장
- 잘못된 날짜·중복 날짜·중복 변수 정의·필수 지표 누락 차단, 결측/잘못된 수치 진단

## 실제 Excel 명세와 갱신

`DailyRate`의 5행 Category, 6행 Ticker, 7행 Notation, 8행 DATES 변수명, 9행 상세 필드, 10행 이후 날짜/값을 사용합니다. A열이 날짜입니다. 1900/1904 Excel 날짜 체계와 명시된 날짜 문자열을 지원합니다. 숫자와 날짜는 검증하며 예약 빈 행은 제외합니다. 숨김 `AFOSHEET`와 작성자·개인 경로 같은 문서 메타데이터는 가져오지 않습니다.

확인한 원본은 302계열, 2001-01-02~2026-10-13의 6,160개 날짜행입니다. 기존 HTML의 260개 지표는 Category·DATES·상세 필드 조합으로 식별하므로 열이 이동해도 연결됩니다. 추가 42개를 포함한 새로운 계열도 인식하며 이름이 같은 지표는 상세 필드로 구분합니다.

동일 날짜가 중복되면 임의 평균·최종행 선택을 하지 않고 업로드를 거부합니다. 숫자 0과 결측은 구분합니다. 앱은 결측을 이월하거나 0으로 채우지 않습니다. 원본의 `Bizday=101` 옵션은 비거래일 이전값 사용을 포함하므로, 공급 단계에서 이미 이월된 값이 있을 가능성은 별개입니다.

Excel 추가기능을 통해 원본을 갱신한 뒤 저장하고 페이지에서 다시 업로드하십시오. 브라우저는 Excel 수식을 실행하거나 Infomax 추가기능에 접속하지 않습니다. 수식 셀은 저장된 캐시값만 읽습니다. Drive 자동 동기화와 실시간 시세는 제공하지 않습니다.

## 단위와 통계 정의

금리·신용채의 %와 미국 OAS의 bp는 원본 HTML의 해석을 유지한 전제입니다. Excel에 모든 단위가 명시된 것은 아니며 외부 원자료로 확인하지 않았습니다. 기존 260개 정의를 제외한 신규 지표는 `단위:` 표시가 없으면 `원자료`·절대차분으로 취급합니다. 단위 미확인 계열은 수익률 차이 후보에서 제외합니다. FX 방향·배율은 원본 명칭을 확인해야 합니다.

기간·한국 크레딧스프레드는 (A의 % 금리 − B의 % 금리) × 100 bp입니다. OAS는 원본을 bp로 표시하며 국채금리를 차감하거나 다시 100배 하지 않습니다. 선형 보간은 관측값이 아닌 추정값이며 범위 밖 외삽은 하지 않습니다.

회귀·상관은 같은 날짜의 유효 X/Y 관측쌍만 사용합니다. 기초통계는 각 변수의 유효 표본을 별도로 표시합니다. 표본 표준편차는 n−1, OLS 잔차 표준편차는 n−2 분모입니다. 상수 X, 상수 Y, 관측 부족 조건을 구분합니다. 이동창은 원본 관측행 수이며 창 전체에 유효값이 있어야 계산합니다. 시작일 이전 이력은 차분·이동창 준비에 사용할 수 있으나 종료일 이후 값은 사용하지 않습니다. √252 연율화는 사용자가 선택하는 가정입니다. 상관·회귀를 인과나 예측 성능으로 해석하지 않습니다.

## 개발·검증

일반 사용에는 설치가 필요 없습니다. Python 3 표준 라이브러리로 공개 페이지를 재생성합니다.

```bash
python3 scripts/build.py
node tests/public-artifact.cjs
npm test
```

`src/`는 유지보수용 HTML/CSS/JS입니다. 빌드는 모든 실행 코드·스타일·JSZip을 `index.html`과 배포용 `dist/index.html`에 넣습니다. 관측값을 빌드에 입력하는 경로는 없습니다. `src/reference-meta.json`은 기존 260개 지표 정의만 포함합니다. 상대 경로 및 하위 `/econ/` 경로에서도 동작하도록 결과물이 자체 완결됩니다.

PR의 `Validate dashboard`는 공개 데이터 유출 검사·단위 테스트·Chromium 브라우저 회귀 테스트를 실행합니다. 브라우저 테스트에는 명시적인 합성 Excel fixture만 사용합니다. 원본 Excel을 공개 CI에 업로드하지 않습니다. 테스트 범위와 실제 실행 결과는 [검증 기록](docs/VALIDATION.md)에 기록합니다.

## GitHub Pages

1. 저장소 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
2. 검토된 PR을 소유자 승인 후 `main`에 병합합니다.
3. `Deploy GitHub Pages`가 테스트·빌드 후 `dist/`만 배포합니다. 작업 브랜치나 PR에서는 배포하지 않습니다.
4. Actions의 배포 URL을 확인하고 공개 접속·새로고침·업로드를 별도로 검증합니다.

Pages 설정 도구는 현재 연결된 GitHub 도구에 없어 최초 Source 선택은 저장소 설정 화면에서 해야 합니다. 데이터 공개 없이 코드만 배포하며, 배포 시 유료 서버는 사용하지 않습니다.

## 원본 대비 변경·제한

기존 UI와 분석 기능을 유지하면서 데이터 없는 초기 화면, 추가 계열 인식, 차트 조작, 일반 이동평균·기초통계·X/Y 비교, 입력 진단을 추가합니다. 기존 README는 실제 저장소 파일과 맞지 않는 설명이 있어 현재 상태로 정정했으며 [변경 전 기록](docs/README-before-20261015.md)을 남깁니다.

원본 파일·내장 관측값·개인 경로·수정자 이름·Drive 비공개 링크는 공개하지 않습니다. 원천자료의 시장 정확성과 재배포 라이선스는 미확인입니다. 원자재 등 원본에 없는 지표는 생성하지 않습니다. 다변량·인과 회귀, 미래 예측, 원천시세 API 연결은 제공 범위에 없습니다.

JSZip 3.10.1의 원본 라이선스 고지는 `src/jszip.min.js`와 빌드 HTML 안에 보존합니다. 원본 대시보드 코드의 별도 라이선스를 새로 부여하지 않습니다.
